# connectatel-analysis-final-proyect-sprint7
Este repositorio contiene el análisis y la ejecución final del proyecto para el sprint 7 del la empresa ConnectaTel
El objetivo fue analizar el negocio usando los 3 datasets (clientes, uso_real y planes) para que ConnectaTel entienda cómo se comportan sus usuarios según edad, volumen de llamadas/mensajes y nivel de consumo.

## 📂 Contenido del repositorio

- `notebooks/ S7Version-Estudiante-Project-ConnectaTel.ipynb`
  → Notebook principal con limpieza, EDA, distribuciones, outliers y conclusiones.

## 🧠 Objetivo del análisis

- Identificar problemas de calidad de datos
- Analizar comportamientos, distribuciones y outliers
- Generar insights para entender cómo los clientes usan realmente los servicios móviles (llamadas y mensajes).
